# Vidyarthi.ai V7.1 — Launch + SEO Build

## Deployment
Upload the contents of this folder to the document root for vidyarthi.ai (normally `public_html`). `index.html` must sit directly inside the document root.

## SEO included
- Page-specific title and meta description
- Canonical URLs
- Robots directives
- Open Graph metadata
- Twitter card metadata
- WebPage JSON-LD
- Organization + WebSite JSON-LD on the homepage
- English/Hindi/Bengali hreflang on the main language pages
- Updated sitemap.xml
- robots.txt with sitemap reference

SEO improves crawlability and relevance; rankings are not guaranteed and will improve as real, useful content, links and search performance accumulate.
